# Data Notice

This repository does not contain raw RAD or Real-IAD image datasets.

Included data files are derived score exports, audit summaries, configuration records, and figure-generation tables created from registered experiments. Users must obtain benchmark datasets from their original providers and comply with their licenses and access conditions.

No third-party model weights, PatchCore checkpoint binaries, or upstream datasets are redistributed in ordinary Git history. Release-only assets retain their original licensing boundaries.
